API & Feed

A free, open feed of RWA news for developers. No authentication. No rate limits. Drop a script tag on your page or fetch the JSON in your backend. 91 articles and growing daily.

Free No auth required CORS enabled Updated daily
Endpoints
GET   JSON Feed
https://rwatoday.news/feed.json
JSON Feed 1.1 spec with RWAToday extensions. Returns all articles with title, URL, excerpt, category, date, and tags. Ideal for custom integrations, dashboards, and data pipelines.
GET   RSS Feed
https://rwatoday.news/feed.xml
Standard RSS 2.0 feed. Compatible with any RSS reader, CMS plugin, Zapier, Make, or news aggregator.
GET   Embed Widget
https://rwatoday.news/widget.js
Drop-in JavaScript widget. Add a <div> and a <script> tag — no backend required. Configurable count, category filter, and dark/light theme.

Implementation Examples

Fetch the latest 5 articles in JavaScript:

// Vanilla JavaScript
fetch('https://rwatoday.news/feed.json')
  .then(r => r.json())
  .then(data => {
    const articles = data.items.slice(0, 5);
    articles.forEach(article => {
      console.log(article.title, article.url);
    });
  });

Filter by category:

fetch('https://rwatoday.news/feed.json')
  .then(r => r.json())
  .then(data => {
    const markets = data.items.filter(item =>
      item._rwatoday.category.includes('Markets')
    );
  });

Python / backend:

import requests

response = requests.get('https://rwatoday.news/feed.json')
feed = response.json()

for article in feed['items'][:10]:
    print(article['title'], article['url'])
Embed Widget

Add RWA news to any page with two lines of HTML. No backend, no API key, no configuration required.

<!-- Basic embed (5 articles, dark theme) -->
<div id="rwatoday-feed"></div>
<script src="https://rwatoday.news/widget.js" async></script>

<!-- 3 articles, light theme -->
<div id="rwatoday-feed"
     data-count="3"
     data-theme="light"></div>

<!-- Markets articles only -->
<div id="rwatoday-feed"
     data-category="Markets"
     data-count="5"></div>
Widget Options
AttributeValuesDefaultDescription
data-count1–205Number of articles to display
data-themedark / lightdarkColor scheme
data-categoryAny string—Filter by category keyword (e.g. "Markets", "Policy", "Education")
data-titletrue / falsetrueShow/hide the RWAToday.news header
